# 폴리곤 지갑 등록소

폴리곤 체인의 지갑 주소에 **"누구 것인지"** 이름을 붙여 함께 모으는 도구입니다.

체인 위의 거래 기록은 누구나 볼 수 있지만 거기 찍힌 것은 `0x`로 시작하는 42자리 주소뿐입니다.
그 주소가 누구 것인지 알아야 흐름이 읽힙니다. 한 사람이 아는 것은 한두 개지만, 여럿이 아는 것을 모으면 지도가 됩니다.

**최종 목표** — 회사와 관련 인물의 주소를 충분히 모아, 나중에 개인 거래내역만 보고도 자금이 어디서 들어와 어디로 빠져나갔는지 따라갈 수 있게 하는 것.

---

## 구성

| 파일 | 하는 일 |
|---|---|
| `지갑등록소.html` | 등록·추천·현황 웹페이지. 카페에 링크로 올리는 것이 이 파일입니다. |
| `apps_script/Code.gs` | 백엔드. 구글 스프레드시트에 등록·추천을 저장합니다. |
| `labels.json` | 운영진이 확정한 라벨 사전. 등록소와 확장 프로그램이 함께 읽습니다. |
| `폴리곤스캔_이름표.user.js` | 폴리곤스캔 화면의 주소를 등록된 이름으로 바꿔 보여주는 확장 스크립트. |
| `카페_공지글.md` | 네이버 카페에 붙여넣을 안내글 초안. |

---

## 설치 (순서대로)

### 1. 백엔드 만들기 — 10분

1. 구글 스프레드시트를 새로 만듭니다.
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. `apps_script/Code.gs` 내용을 통째로 붙여넣고 저장합니다.
4. 위쪽 함수 목록에서 **`setup`** 을 고르고 **▶ 실행** 합니다. (최초 1회, 권한 승인 필요)
   → `entries` · `votes` · `lookups` 시트 3개가 생깁니다.
5. **배포 → 새 배포 → 유형 '웹 앱'**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 반드시 이 값이어야 카페 회원이 쓸 수 있습니다
6. 나오는 `.../exec` 주소를 복사해 둡니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필(수정) → 버전 '새 버전' → 배포** 로 기존 배포를 수정하세요.
> 새 배포를 또 만들면 주소가 바뀝니다.

### 2. 페이지에 주소 넣기

`지갑등록소.html` 맨 아래 `<script>` 첫 부분:

```js
var API_URL    = 'https://script.google.com/macros/s/....../exec';   // 5단계에서 복사한 주소
var LABELS_URL = 'labels.json';                                       // GitHub raw 주소 권장
```

`LABELS_URL` 은 GitHub Pages로 올릴 경우 같은 폴더의 `labels.json` 이라 그대로 두어도 됩니다.

### 3. 페이지 올리기

GitHub Pages가 가장 간단합니다. 저장소 **Settings → Pages → Branch: main / (root)** 로 켜면
`https://<계정>.github.io/<저장소>/지갑등록소.html` 로 접속됩니다. 이 주소를 카페에 올립니다.

### 4. (선택) 폴리곤스캔 이름표

크롬에 [Tampermonkey](https://www.tampermonkey.net/) 를 설치한 뒤 `폴리곤스캔_이름표.user.js` 를 추가하고,
파일 위쪽 두 줄을 채웁니다.

```js
const LABELS_URL   = 'https://raw.githubusercontent.com/<계정>/<저장소>/main/labels.json';
const REGISTRY_URL = 'https://script.google.com/macros/s/....../exec';
```

폴리곤스캔에서 주소가 등록된 이름으로 바뀌어 보이고, 그 자리에서 바로 이름을 달 수 있습니다.

## 어떻게 굴러가나

### 같은 이름은 하나로 묶입니다

`강남센터 총판` · `강남 센터 총판` · `강남센터총판` 은 **같은 이름**으로 봅니다.
세 사람이 따로 올려도 표가 갈리지 않고 **"제보 3명"** 짜리 후보 하나가 됩니다.

### 신뢰도

| 등급 | 조건 |
|---|---|
| **확정** | 운영진이 `labels.json` 에 `confidence: "A"` 로 넣은 것 |
| **유력** | 제보자 2명 이상 **또는** 추천 3표 이상, 그리고 "아니다"가 0 |
| **가능성** | 추천 1표 이상 |
| **미검증** | 제보 1건뿐 |

점수 = `추천×2 − 아니다×3 + (제보자수−1)×4 + (출처종류−1)×2 + 출처가중치`

**서로 다른 사람이 서로 다른 경로로 같은 이름을 냈을 때**가 가장 강합니다.
그래서 "어떻게 아셨나요?"를 필수로 받습니다 — 나중에 증거력을 가르는 항목입니다.

| 출처 | 가중치 |
|---|---|
| 내가 이 주소로 보냈음 / 받았음 / 공지에 있던 주소 | 3 |
| 단톡방에서 안내받음 / 남의 내역에서 봄 / 거래 흐름으로 추정 | 2 |
| 들어서 알고 있음 | 1 |

### 도와주세요 (수배 목록)

누군가 주소를 확인했는데 이름이 없으면 `lookups` 시트에 조회수가 쌓입니다.
**여러 사람이 찾아본 주소일수록 위로** 올라갑니다. 누가 이름을 달면 목록에서 자동으로 빠집니다.

운영진이 먼저 물어보고 싶은 주소는 `labels.json` 의 `wanted` 에 넣으면 맨 위에 고정됩니다.

```json
"wanted": [
  { "address": "0x....", "reason": "회사 지급지갑이 가장 큰 금액을 보낸 주소" }
]
```

### 개인정보 차단

전화번호 · 주민번호 · 계좌번호로 보이는 숫자는 **화면과 서버 양쪽에서** 막습니다.
지갑 이름에는 닉네임이나 직책만 씁니다.

## 모은 데이터 쓰기

전체 현황 탭 아래 두 개의 내려받기 버튼이 있습니다.

- **labels.json** — 확장 프로그램이 읽는 사전. 커뮤니티 등록분 중 기준을 넘은 것만 `(추정)` 을 붙여 넣습니다.
  받은 파일을 저장소의 `labels.json` 에 덮어쓰면 모두의 폴리곤스캔 화면에 반영됩니다.
- **CSV** — 자금 흐름을 정리할 때 쓰는 표. `주소 / 대표이름 / 분류 / 신뢰도 / 추천 / 제보자수 / 제보자 / 출처 / 시점 / 소속 / 근거 / 폴리곤스캔 링크`

자금추적은 **주소에 이름이 붙어 있어야** 시작할 수 있습니다.
CSV 의 `주소 → 이름` 만 있으면 폴리곤스캔에서 받은 거래내역에 그대로 붙여 흐름을 읽을 수 있습니다.

## 운영 시 알아둘 것

- **Apps Script 무료 한도** — 동시 실행 30개. 페이지는 8초마다 "바뀐 게 있는지"만 묻는 아주 가벼운 요청을 보내고,
  값이 달라졌을 때만 전체를 다시 받습니다. 수십 명이 동시에 봐도 견딥니다.
- **쓰기 제한** — 닉네임 하나당 시간당 80회. `Code.gs` 의 `MAX_WRITE_PER_HOUR` 에서 조절합니다.
- **잘못 올라온 항목 삭제** — `Code.gs` 의 `ADMIN_KEY` 에 아무 문자열이나 넣고 배포한 뒤,
  `{action:'remove', id:'E....', key:'그 문자열'}` 을 POST 하면 해당 항목이 숨겨집니다.
  (시트의 `status` 칸에 직접 `deleted` 를 적어도 됩니다.)
- **백업** — 스프레드시트가 원본입니다. 가끔 사본을 떠 두세요.

## 주의

여기 모이는 이름은 **확정된 사실이 아니라 커뮤니티가 모은 추정**입니다.
특정 개인·법인의 위법행위를 단정하지 않으며, 실명·연락처는 기록하지 않습니다.
정정·삭제 요청은 운영진이 확인 후 처리합니다.
